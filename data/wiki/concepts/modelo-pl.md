# Modelo de Programación Lineal

Un **modelo de Programación Lineal** es la **representación matemática** de un problema de optimización en el que **tanto la función objetivo como las restricciones son lineales**.

Un modelo de PL queda completamente especificado cuando se definen:

1. Las **variables de decisión** (qué se quiere determinar).
2. La **función objetivo** (qué se quiere maximizar o minimizar).
3. El sistema de **restricciones** (qué limitaciones existen).
4. Las **condiciones de no negatividad** sobre las variables.
