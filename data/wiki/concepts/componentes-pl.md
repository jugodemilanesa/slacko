# Componentes básicos de un modelo de PL

Todo modelo de Programación Lineal está compuesto por **cuatro elementos** fundamentales:

1. **Variables de decisión** — representan aquello que se va a determinar matemáticamente (cantidad a fabricar, dinero a invertir, horas a asignar). Se notan x₁, x₂, …, xₙ.
2. **Función objetivo** — meta a optimizar (maximizar ganancias o minimizar costos). Tiene la forma Z = c₁x₁ + c₂x₂ + … + cₙxₙ.
3. **Restricciones** — limitaciones operativas, físicas o de contexto. Se formulan como inecuaciones o ecuaciones lineales: Σ aᵢⱼ xⱼ ≤ (o ≥ o =) bᵢ.
4. **Condiciones técnicas (no negatividad)** — xⱼ ≥ 0 para todo j.
